# Installation des V0.34-Patches

1. ZIP entpacken.
2. Im bestehenden funktionierenden GitHub-Repository `Add file → Upload files` öffnen.
3. Den gesamten Inhalt des entpackten Patch-Ordners hochladen.
4. Vorhandene Dateien überschreiben.
5. Commit-Nachricht: `Add V0.34 Local Garden Intelligence`
6. Auf `main` speichern.
7. Das neue Vercel-Deployment abwarten.

Das Patch enthält bewusst keine `package.json` und keine `package-lock.json`.

Nach der Veröffentlichung muss oben sichtbar sein:

`V0.34 LOCAL GARDEN INTELLIGENCE`

Der neue Button lautet:

`Bestätigen & direkt zeichnen`
