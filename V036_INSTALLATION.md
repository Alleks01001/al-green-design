# V0.36 installieren

Dieses Paket ist ein Patch für die funktionierende V0.35/V0.31-Projektbasis.

1. ZIP vollständig entpacken.
2. Im bestehenden GitHub-Repository `Add file` → `Upload files` wählen.
3. Den Inhalt des Patch-Ordners direkt in das Repository-Hauptverzeichnis ziehen.
4. Vorhandene Dateien überschreiben.
5. Commit-Nachricht: `Add V0.36 Smart Draw Toolbar`
6. Das neue Vercel-Deployment abwarten.

Das Patch enthält keine `package.json` und keine `package-lock.json`. Die funktionierende npm-Konfiguration wird nicht verändert.
