# GitHub Upload

1. ZIP auf dem iPhone in der Dateien-App entpacken.
2. Im GitHub-Repository **Add file → Upload files** öffnen.
3. Den Inhalt des entpackten Ordners hochladen, nicht die ZIP-Datei.
4. Direkt in den Haupt-Branch committen.
5. Commit-Nachricht: `AL Green Design Studio 2.2 BIM Engine`
6. Vercel startet danach automatisch den neuen Build.
