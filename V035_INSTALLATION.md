# Installation V0.35

1. ZIP vollständig entpacken.
2. Das bestehende funktionierende GitHub-Repository öffnen.
3. **Add file → Upload files** auswählen.
4. Den gesamten Inhalt des entpackten Patch-Ordners hochladen.
5. Vorhandene Dateien überschreiben.
6. Commit-Nachricht: `Add V0.35 Adaptive Garden Intelligence`
7. Auf `main` speichern und das Vercel-Deployment abwarten.

Nach dem Deployment muss sichtbar sein:

```text
V0.35 ADAPTIVE GARDEN INTELLIGENCE
```

Der Hauptbutton lautet:

```text
Bestätigen, lernen & direkt zeichnen
```
