# AL Green Design Studio 3.0 Alpha.6

## PDF-Plan

- PDF-Dateien können direkt im Importbereich ausgewählt werden.
- Die erste PDF-Seite wird als hochauflösende Zeichenreferenz unter dem CAD gerendert.
- Breite, Tiefe, Deckkraft und Sichtbarkeit bleiben einstellbar.
- Die Referenz wird zusammen mit der `.algreen`-Projektdatei gespeichert.
- Die sichtbare 2D-Zeichenansicht kann als A4-Querformat-PDF exportiert werden.

## Neu beginnen

- Die Schaltfläche **Alles löschen** entfernt Objekte, BIM-Daten und die Planreferenz gemeinsam.
- Das Gelände wird deaktiviert und die Arbeitsfläche auf 2D zurückgesetzt.
- Die vorherige Projektfassung bleibt unmittelbar über **Rückgängig** wiederherstellbar.
