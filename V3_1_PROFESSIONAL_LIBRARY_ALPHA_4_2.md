# V3.1 Professional Library Alpha 4.2

## Behobene Probleme

- Die Professional Library wird nicht mehr als kleines Kartenraster in das schmale Studio-Seitenpanel gezwängt.
- Ein stabiler Datenbank-Startbereich öffnet Pflanzen, Bauweisen, Objekte und Materialien auf einer eigenen Vollseite unter `/library`.
- Jede Karte besitzt eine eindeutige Aktion „Zum Projekt hinzufügen“ und zeigt danach eine sichtbare Erfolgsbestätigung.
- Pflanzen, Objekte und Bauweisen werden beim Hinzufügen sofort ausgewählt und zusammen mit ihren BIM-Daten gespeichert.
- Die beim Wechsel zur Datenbank bestehende Auswahl bleibt erhalten, damit Materialien auf ausgewählte Projektobjekte angewendet werden können.
- Die lokale Speicherung beginnt erst, nachdem vorhandene Projektdaten vollständig geladen wurden. Dadurch kann der leere Startzustand gespeicherte Ergänzungen nicht mehr beim Öffnen überschreiben.

## Bedienung

1. Im Studio zur Karte „Professional Library“ scrollen.
2. „Pflanzendatenbank öffnen“ oder einen der drei anderen Datenbank-Einstiege wählen.
3. In der großen Datenbank suchen oder filtern.
4. Auf „Zum Projekt hinzufügen“ drücken und die grüne Bestätigung abwarten.
5. „Im Studio ansehen“ oder „Zurück zum Studio“ wählen.
